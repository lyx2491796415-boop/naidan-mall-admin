# 奶娃商城 · 管理后台

一个基于 Vue 3 + Vite 的现代电商后台管理系统。统一的暖金设计语言、深色侧边栏、数据可视化，以及一只会做十几套表情的吉祥物「奶娃」。

## 功能

| 模块 | 说明 |
| --- | --- |
| 经营概览 | 核心指标卡、营收趋势、品类占比、实时动态、快捷入口 |
| 用户管理 | 搜索筛选、分页、新增 / 编辑 / 停用 / 删除、用户详情 |
| 权限管理 | 按角色查看与切换权限，启用开关实时生效 |
| 商品管理 | 增删改查、分类筛选、低库存预警、库存货值统计 |
| 订单管理 | 状态标签、全流程流转（待付款 → 已付款 → 已发货 → 完成） |
| 奶娃表情馆 | 16+ 抽象表情包，点击复制文案，随机推荐 |
| 系统设置 | 站点信息、功能开关、深浅主题、实时预览 |

所有业务数据通过 `localStorage` 持久化，刷新页面不会丢失。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://localhost:5173`）。

> 用 HBuilderX 打开本项目，在内置终端执行上面两条命令即可；也可以用 HBuilderX 的「运行到浏览器」。

演示账号：`admin` / 密码：`123456`

## 生产构建

```bash
npm run build
```

产物输出到 `dist/`。

## 目录结构

```
src/
├─ components/        公共组件（布局、图标、数据卡、奶娃）
│  └─ Mascot.vue      纯 SVG 吉祥物，mood 属性切换表情
├─ views/             各功能页面
├─ styles/theme.css   全局设计变量与主题
├─ store.js           集中式响应式数据 + 持久化
├─ router.js          路由与登录守卫
└─ main.js
```

## 技术栈

Vue 3（Composition API）· Vue Router 4 · Vite 5 · Less
